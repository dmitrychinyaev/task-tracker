# Git Push Workflow

Автоматически коммитит и пушит изменения после завершения задачи.

## Шаги

1. Проверь статус репозитория: `git status`
2. Если есть незакоммиченные изменения, добавь все файлы: `git add .`
3. Создай коммит с осмысленным сообщением на основе изменений (например: "feat: add task filtering"): `git commit -m "<сообщение>"`
4. Отправь изменения на GitHub: `git push origin master`
5. Сообщи пользователю, что изменения успешно запушены.
