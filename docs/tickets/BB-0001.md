# BB-0001 - Mobile-Responsive Frontend

## Status

Implemented

## Date

2026-11-04

## Problem

The web UI was desktop-only:

- the sidebar occupied a fixed 220px column, unusable on a 375px screen;
- Kanban columns had a fixed 240px width inside a horizontally scrolling board;
- data tables had no scroll container, so every wide table forced a
  page-level horizontal scrollbar;
- some form rows used inline flex styles that did not stack on narrow screens;
- action buttons were too small for comfortable touch input.

## Goal

Make the React frontend usable on screens narrower than 768px without
changing desktop behaviour:

- collapsible hamburger sidebar;
- swipeable Kanban columns;
- horizontal scroll only inside tables, never for the whole page;
- single-column, touch-friendly task form.

## Changes

### 1. Mobile navigation - `frontend/src/components/Layout.tsx`

- added `menuOpen` state and a mobile-only `topbar` header with a hamburger
  button (`aria-label="Menu"`, `aria-expanded`);
- the existing `sidebar` becomes a fixed drawer, toggled by the `open` modifier;
- added a `sidebar-backdrop` overlay that closes the drawer on tap;
- the drawer closes on navigation item click and on route change
  (`useEffect` on `location.pathname`, which also covers links clicked inside pages).

### 2. Responsive styles - `frontend/src/styles.css`

New base classes: `.topbar` (`display: none` on desktop), `.menu-toggle`,
`.sidebar-backdrop`, `.table-wrap`, `.link-row`, `.link-label`, `.button-row`.

`@media (max-width: 768px)`:

| Rule | Effect |
|---|---|
| `.app-shell` | `flex-direction: column`, `height: 100dvh` (`100vh` fallback) |
| `.sidebar` | `position: fixed`, `translateX(-100%)`, `max-width: 82vw`, `z-index: 80`, vertical scroll |
| `.sidebar.open` | `translateX(0)` - drawer slides in |
| `.sidebar-backdrop` | full-screen overlay, `z-index: 70` |
| `.main` | `overflow-x: hidden`, reduced padding, `min-height: 0` |
| `.btn` / `.btn.small` | `min-height: 44px` / `40px` touch targets |
| `.form-actions` | stacked, full-width buttons |
| `.link-row` / `.button-row` | stacked links, wrapping button row |
| `.board-col` | `width: 85vw` - one Kanban column per swipe |
| `.table-wrap table` | `min-width: 640px` - scrolls inside the wrapper only |

### 3. Task form - `frontend/src/pages/TaskFormPage.tsx`

Three inline styles replaced with the new classes: `button-row`, `link-row`,
`link-label`.

### 4. Table overflow

`<table>` wrapped in `<div className="table-wrap">` in:

- `frontend/src/pages/BacklogPage.tsx`
- `frontend/src/pages/ArchivePage.tsx`
- `frontend/src/pages/AssigneesPage.tsx`
- `frontend/src/pages/InboxPage.tsx`
- `frontend/src/pages/SprintsPage.tsx`

### 5. Backend static mount - `backend/app/main.py`

Already modified in the working tree before this task and included in the same
commit: mounts the built frontend (`frontend_dist`) with
`StaticFiles(html=True)` when the directory exists.

`frontend/src/App.tsx` was not changed - it only declares routes; menu logic
lives in `Layout.tsx`. The files `index.css` / `App.css` do not exist in this
project; all styles are in `styles.css` (imported from `main.tsx`).

## Desktop behaviour

Unchanged: `.topbar` is hidden above 768px, the sidebar stays in the flex row,
tables keep `width: 100%`, and the Kanban board keeps fixed 240px columns.

## Migrations

None. No database schema, model, or API changes.
